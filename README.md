# 💳 Financial Fraud Detection — ML + GenAI + Dashboard

A personal end-to-end financial fraud detection system combining a Random Forest ML model, a local LLM (Llama 3 via Ollama) for generating investigation reports, and a dark-mode web dashboard for investigators.

---

## 🧠 How It Works

```
PaySim Dataset (CSV)
      ↓
  data.py  →  Builds SQLite database (fraud_database.db)
      ↓
  ML.py    →  Trains Random Forest → Detects fraud → Sends flagged cases to Llama 3
      ↓
 Ollama (local LLM)  →  Generates professional AML alert report (EN + AR)
      ↓
dashboard.html  →  Interactive dark-mode investigation UI
```

---

## ✨ Features

- **ML Model** — Random Forest (100 trees, class-weight balanced) trained on PaySim financial transaction data
- **Feature Engineering** — `errorBalanceOrig` and `errorBalanceDest` signals that catch balance manipulation
- **GenAI Reports** — Llama 3 running locally via Ollama generates a bilingual (English + Arabic) AML alert for each flagged transaction
- **Investigation Dashboard** — Single-file HTML dashboard with:
  - KPI strip (transactions analyzed, fraud rate, pending review)
  - Risk score visualization per transaction
  - Balance flow diagram highlighting anomalies
  - Investigator decision panel (Confirm / Clear / Escalate / Pending)
  - Full audit trail per case
  - Model performance tab (Accuracy, Precision, Recall, F1, Confusion Matrix, Feature Importances)

## ⚙️ Setup & Usage

### 1. Install dependencies

```bash
pip install pandas scikit-learn joblib requests
```

### 2. Download the dataset

Download `paysim.csv` from [Kaggle — PaySim](https://www.kaggle.com/datasets/ealaxi/paysim1) and place it in the project folder.

### 3. Build the database

```bash
python data.py
```

### 4. Train the model & run GenAI analysis

Make sure [Ollama](https://ollama.com) is running with Llama 3 installed:

```bash
ollama pull llama3
ollama serve
```

Then run:

```bash
python ML.py
```

This will:
- Load and clean data from the database
- Engineer balance-error features
- Train a Random Forest (saved as `fraud_model.joblib`)
- Print evaluation metrics and feature importances
- Pick a confirmed fraud case and send it to Llama 3 for an AML report

### 5. Open the dashboard

Just open `dashboard.html` in any browser — no server needed.
